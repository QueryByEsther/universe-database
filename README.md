#  Universe Database

## Project Overview

The Universe Database is a relational database built using PostgreSQL. It organises information about galaxies, galaxy types, stars, planets and moons.

This project demonstrates how related information can be stored, connected and managed using SQL.

## Database Structure

The database contains five main tables:

| Table | Description |
|---|---|
| `galaxy` | Stores information about galaxies. |
| `galaxy_type` | Stores different galaxy classifications. |
| `star` | Stores information about stars. |
| `planet` | Stores information about planets. |
| `moon` | Stores information about moons. |

## Technologies Used

- PostgreSQL
- SQL

## Concepts Demonstrated

- Creating relational database tables
- Primary keys and foreign keys
- Data types and constraints
- Table relationships
- Inserting and managing records
- Writing SQL queries
